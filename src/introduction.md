# Introduction

This book is a focused reference for Rust's core concepts, written for engineers who want depth
rather than breadth. Each article follows the same structure: a prose explanation of *why* the
concept exists, a self-contained code example, a list of rules worth memorising, and a concise
code-review section that shows the right and wrong way to apply the idea in practice.

The topics are grouped by theme — Ownership, Lifetimes, Iterators, and Traits — so you can read
a section end-to-end or jump straight to the article that answers your current question. Every
example compiles against stable Rust and is kept short enough to fit in your head.

If you spot an error or want to suggest an improvement, use the "Edit this page" link in the
top-right corner of any article.
